Sobre o Site

O que é este site?

Este site foi desenvolvido como trabalho acadêmico para a aula de Programação Web, com o objetivo de mostrar as informações sobre a profissão de Designer Gráfico.

O projeto explica desde a definição da profissão, suas áreas de atuação e habilidades necessárias, incluindo salários e empresas empregadoras.

O visual do site foi feito inspirado no Design Gráfico Bauhaus - movimento que uniu arte, artesanato e tecnologia - utilizando tipografia bold, cores primárias e geometria como base.

Site feito em: HTML5, CSS3.
