# computational-thinking.

### pillars:

- 1 Decomposition:
The first pillar consists of breaking down the overall problem into smaller parts that are easier to solve separately

- 2 Pattern Recognition:
By observing the problem data, it is possible to identify patterns that repeat throughout the algorithm; these repetitions aid in organization and problem-solving.

- 3 Abstraction:
Focuses only on the information essential to solving the problem, ignoring unnecessary details.

- 4 Algorithm:
The step-by-step process for solving the problem from start to finish (the code).
